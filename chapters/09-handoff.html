Definition of Ready vs Done

Two gates every design ticket should pass.

🚦 Definition of Ready

Before a developer picks it up
  • All states and breakpoints designed
  • Final copy, no lorem ipsum
  • Uses existing components, or new ones flagged
  • Edge cases and errors covered
  • Testable acceptance criteria
  • Engineering has reviewed feasibility

✅ Definition of Done

Before it ships
  • Design QA passed (designer signed off)
  • Tested on target devices and breakpoints
  • Accessibility checked: keyboard, contrast, labels
  • Analytics events firing
  • Acceptance criteria met
  • Design file updated to match what shipped

Turn a design into acceptance criteria

Given / When / Then makes "like the design" testable.

❌ Vague

  • "Coupon field works like the design"
  • "Show an error if the code is wrong"

✅ Testable

Givena cart over €15 WhenI apply an expired code ThenI see "This code expired on 12 Oct" under the field, and the total doesn't change

🎯 Key takeaways

  • Most design bugs are missing specs, not careless developers.
  • A handoff needs all states, breakpoints and edge cases, not one pretty frame.
  • Handoff is ongoing: involve devs early, run design QA before shipping.
